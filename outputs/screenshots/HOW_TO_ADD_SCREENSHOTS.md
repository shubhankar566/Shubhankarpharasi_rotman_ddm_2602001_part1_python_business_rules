# Screenshots Folder

This folder should contain screenshots of YOUR program actually running
on your own computer or terminal.

WHY YOU MUST DO THIS PART YOURSELF:
Screenshots are meant to prove that you personally ran the program.
A teacher can immediately tell if a screenshot is fake or copied, so
this is one part of the assignment you should generate yourself —
it only takes 2 minutes.

HOW TO DO IT (Windows / Mac / Linux - all similar):

1. Open a terminal (Command Prompt / PowerShell / Terminal app) inside
   this project folder.
2. Run the program:
       python main.py
   (or `python3 main.py` on Mac/Linux)
3. Walk through the menu - try option 1 (customer profile), then
   option 2 (billing), then option 3 (loan), then option 4 (campaign).
4. Take screenshots at a few key points, for example:
       screenshot_01_menu.png            -> the main menu
       screenshot_02_customer_summary.png -> after entering customer details
       screenshot_03_billing_summary.png  -> after the billing calculation
       screenshot_04_loan_decision.png    -> after the loan eligibility result
       screenshot_05_invalid_input.png    -> a moment where you typed an
                                              invalid value (e.g. negative age)
                                              and the program asked you to
                                              retry, to prove validation works
5. Save the screenshot image files directly into this folder
   (outputs/screenshots/), replacing or alongside this README.

On Windows: Press Windows + Shift + S, or use Snipping Tool.
On Mac: Press Cmd + Shift + 4.
On Linux: Use the Screenshot app, or `gnome-screenshot`.

Once you've added your images, you can delete this text file or leave
it — either is fine, it will not affect your grade either way.
